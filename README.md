An interactive Tableau dashboard and comprehensive analytical project exploring regional, economic, operational, and contextual consumer food ordering trends.

## 🚀 Project Overview
This project examines consumer food ordering habits through various analytical lenses, including regional order distributions, cuisine preferences, pricing dynamics, delivery fees, and contextual factors like weather impacts.
